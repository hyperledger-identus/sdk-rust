# identus-core

Chain-neutral core error, time, URL, and capability types for the Hyperledger
Identus Rust SDK.

This package is part of the unpublished `0.1.0-rc.1` cryptography candidate.
It is experimental, is not published to crates.io, and carries no production or
long-term compatibility promise.

See the [SDK repository](https://github.com/hyperledger-identus/sdk-rust), its
[release policy](https://github.com/hyperledger-identus/sdk-rust/blob/develop/RELEASING.md),
and the Apache-2.0 license.
