# Transcript Fixtures

Use this directory for protocol transcript replay fixtures that should run
without external services.

Expected future layout:

```text
<spec-id>/
  transcripts/*.json
  README.md
```

Seeded transcript families:

- `didcomm/`: DIDComm and mediator protocol transcripts.
- `openid4vc/`: OID4VCI, OID4VP, SIOPv2, HAIP, and OpenID Federation logical
  transcripts.
