# SDK-Rust crypto train 0.1.0-rc.1

This is the first experimental crates.io release train from Hyperledger
Identus SDK-Rust:

- `identus-derive`: validated-newtype and port-marker procedural macros;
- `identus-core`: chain-neutral foundational errors, time, URL, and capability
  types;
- `identus-crypto`: reusable key, signature, hash, derivation, JWK, and COSE
  primitives.

The train requires Rust 1.89.0 or newer and is validated primarily with Rust
1.98.1. Internal dependencies are pinned exactly to `0.1.0-rc.1`.

This prerelease is experimental. It does not provide wallet custody, storage,
ledger or DID-method behavior, product policy, certification, supported FFI
packages, or a long-term compatibility promise. WASM, iOS ARM64, and Android
ARM64 evidence is compile-only for this train.

See the [release handbook](https://hyperledger-identus.github.io/sdk-rust/),
[release policy](https://github.com/hyperledger-identus/sdk-rust/blob/develop/RELEASING.md),
and attached machine-readable receipt, crate archives, SBOMs, and provenance.

If a package is defective, stop adoption and consult the release issue before
yanking. Published crates and versions are immutable; corrected code receives
a new version.
