# identus-did

Chain-neutral DID primitives for the Hyperledger Identus Rust SDK.

This crate provides validated DID and DID URL values, DID documents, service
and verification-method models, and resolver-facing data types. It does not
select a DID method, ledger, network, transport, or wallet policy.

The crate is experimental. The `0.1.0-rc.1` candidate is assembled and tested
without changing the unpublished workspace manifest; publication requires a
separate reviewed activation change.
