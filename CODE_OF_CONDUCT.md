# Code of Conduct

Participation in this repository is governed by the
[Hyperledger Code of Conduct](https://toc.hyperledger.org/governing-documents/code-of-conduct.html)
and the [Identus project copy](https://github.com/hyperledger-identus/.github/blob/main/CODE_OF_CONDUCT.md).

The policy applies to people and automated contributions in all repository,
review, meeting and community channels. Human contributors remain accountable
for messages and changes submitted through an agent.
